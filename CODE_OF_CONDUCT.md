# Code of conduct

This project is a small technical repository, and the expectations are correspondingly simple.

## What we expect

- **Be civil.** Disagree with the code, the design or the decision, not with the person. Assume the
  other party is competent and acting in good faith until you have real evidence otherwise.
- **Keep it on topic.** Issues and pull requests are about this extension. Take unrelated arguments
  elsewhere.
- **Accept that "no" is an answer.** Maintainers can decline a feature or an approach without owing
  an essay. If a decision surprises you, ask for the reasoning once, then move on.
- **Respect people's time.** Read the README and the contribution guide before asking, and give
  enough detail that someone can help you without three rounds of questions.

## What is not acceptable

Harassment, insults, discriminatory or sexualized language, personal attacks, deliberate
intimidation, publishing someone's private information, and repeatedly pushing an argument after it
has been settled. This applies to issues, pull requests, commit messages, code and any other
interaction in this repository.

## Enforcement

Maintainers may edit, hide or delete contributions that break these expectations, and may block an
account from the repository. We aim to warn first and act proportionately, but a serious or repeated
breach can lead to an immediate block.

## Reporting

Email support@cloud-iam.com with `event-forwarder code of conduct` in the subject, and a link to what
you are reporting. Reports stay confidential, and we will not discuss them publicly. If your report
concerns a maintainer, say so and it will be handled by someone else.
